# Financial-Fraud-Detection-Risk-Analytics
Financial fraud detection and risk analytics project using SQL, Python, machine learning and Power BI.

# Project Overview

A data analytics and risk monitoring project designed to analyse financial transactions, identify fraudulent activity, assess transaction risk, and present actionable insights through an interactive Power BI dashboard.

The project combines SQL, Python, Machine Learning and Power BI to move from transaction-level data to business-level risk insights.

# Business Objective

- Identify and analyse fraudulent transactions
- Monitor fraud cases and overall fraud rate
- Analyse fraud trends over time
- Identify high-risk merchant categories and states
- Assess customer and transaction risk
- Compare machine learning model performance
- Support data-driven fraud risk decisions

# Technology Stack

- Python
- SQL
- Power BI
- Pandas
- Scikit-learn
- XGBoost
- Random Forest
- LightGBM

# Key Analysis

The project focuses on answering questions such as:

1. How many fraudulent transactions are being detected?
2. What is the overall fraud rate?
3. How does fraud activity change over time?
4. Which states have the highest number of fraud cases?
5. Which merchant categories show higher fraud activity?
6. What is the amount currently exposed to fraud risk?
7. Which customers and transactions require further investigation?

# Machine Learning

The project evaluates multiple fraud detection approaches using metrics such as:

- Precision
- Recall
- F1-score
- ROC-AUC

Models include:

- Random Forest
- XGBoost
- LightGBM
- Isolation Forest

# Risk Analytics

Transaction-level risk scores are used to identify and categorise potentially high-risk activity, helping prioritise transactions and customers for further investigation.

# Business Value

The project helps:

- Monitor fraud trends
- Identify high-risk areas
- Prioritise investigations
- Understand merchant-level risk
- Track important fraud KPIs
- Support data-driven risk decisions
